# ABYZOR IZZY Synth

**A free synthesizer. 59 sounds. 8 sound categories. One simple workflow.**

ABYZOR IZZY Synth is a free synthesizer plugin designed to make sound creation fast, intuitive, and accessible.

Choose a sound, generate variations, tweak a few controls, and start playing. No complicated synthesis workflow required.

Version 2.0 introduces a completely rebuilt sound engine, dedicated synthesis architectures, expanded sound categories, and macOS support.

## What's New in Version 2.0

IZZY Synth has been rebuilt from the ground up.

- **59 built-in sounds** across 8 sound categories.
- **8 sound categories:** PAD, KEYS, BELL, ATMOS, BASS, STAB, LEAD, and PLUCK.
- **Dedicated synthesis engines:** each sound uses its own synthesis architecture.
- **Expanded sound generation:** randomized variations for quick exploration.
- **More synthesis possibilities:** analog oscillators, unison, wavetables, string synthesis, FM, ring modulation, wavefolding, and noise.
- **Multiple filter types:** Tone, Ladder, Vowel, and Comb.
- **Modulation and effects:** 2 LFOs, ping-pong delay, chorus, phaser, and reverb.
- **10 macro controls** for shaping and customizing sounds.
- **16-voice polyphony** with MIDI performance controls.

## Features

### Sound Generation

- One-click sound generation and variation.
- 59 sounds organized into 8 categories.
- Dedicated sound engines for different sound characteristics.
- Randomized takes for further experimentation.
- Consistent output levels when generating new sounds.

### Synthesis Engine

- Analog oscillators with up to 7-voice unison.
- 12 built-in wavetables.
- Plucked and bowed string synthesis.
- FM synthesis with feedback.
- Ring modulation.
- Wavefolding.
- Colored noise.
- Tone, Ladder, Vowel, and Comb filters.

### Modulation & Effects

- 2 LFOs with host synchronization.
- Ping-pong delay.
- Chorus.
- Phaser.
- 8-line reverb.

### Performance

- Up to 16-voice polyphony.
- Mono mode and glide.
- Pitch bend.
- Mod wheel.
- Sustain support.
- Built-in MIDI keyboard.

### Interface

- Minimal, hardware-inspired interface.
- Sound category browser.
- Numbered sound selection.
- Dedicated GENERATE workflow.
- 10 intuitive macro controls.
- MOVE function for exploring new variations.
- Return and reset controls.
- Real-time waveform and spectrum visualization.

## Installation

1. Download the latest version from the [Releases](../../releases/latest) page.
2. Install the plugin for your operating system.
3. Open your DAW and scan for new plugins.
4. Load **ABYZOR IZZY Synth** and start creating.

The standalone application can also be launched independently.

For macOS, check the included `INSTALL.txt` for installation instructions.
